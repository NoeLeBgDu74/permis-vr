Commandes

Quest 3 — Attrape le volant avec les gâchettes latérales (ou joystick gauche) · Gâchette droite accélérer · Gâchette gauche freiner · X / Y clignotant gauche / droit · A marche avant / arrière · B klaxon · joystick droit vers l'avant (maintenu) : parler à l'inspecteur · clic joystick droit : recentrer le siège. Attrape le levier de vitesses (pousse / tire : P R N D) et le frein à main (lève pour serrer, baisse pour desserrer) avec la gâchette latérale. Regarde tes rétroviseurs avant de tourner : l'inspecteur le vérifie !
